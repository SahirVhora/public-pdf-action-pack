Public PDF Action Pack

Turn school letters, council notices, NHS appointments, and solicitor documents into plain-English actions, deadlines, and checklists. No AI required.

View on GitHub Run locally

What it does

📄

Upload any public PDF

School trip letters, council tax notices, NHS appointments, solicitor letters - drag and drop or paste text.

🔍

Auto-classify 6 document types

School letters, council notices, NHS guidance, housing/property, HR policy, government guidance.

✓

Action checklist with evidence

Every action links to the source page. Tick boxes. Expand evidence. No guessing what to do.

⚖

Decisions to make

Property docs get ownership, contribution, and wills decision tables with options and what to ask your solicitor.

🎒

Child & prep checklists

School trips extract what to pack. NHS appointments extract what to bring. Context-aware extraction.

📤

Export anywhere

Download Markdown or JSON. Copy a WhatsApp-friendly summary. Works fully offline with deterministic fallback.

Run locally

Terminal

git clone https://github.com/SahirVhora/public-pdf-action-pack.git
cd public-pdf-action-pack
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[test]'
streamlit run app.py

CLI (no browser needed)

PYTHONPATH=src python3 -m action_pack.cli demos/school-trip-letter.pdf --no-ai

offline No API key needed. Turn AI off for deterministic local fallback. 30 tests.
